A <form> can only send GET or POST. Post an intent to reach the others from a form, or use fetch.

Answer a mutation with a redirect

Use a 303, so the URL the browser lands on is a GET and a reload does not submit again. Two things skip it: a rejected submission, which changed nothing, and a region request, which asked for markup.

${html(s.redirect)}

One shape from every handler

ctx.action is the union of what the handlers return. Return the same shape from all of them, or the loader can read none of them.

A body can be read once. A module-level const badRequest = new Response(…) works for the first request and comes back empty after that.

CSRF

On by default, covering non-GET requests that carry a form content type. Set csrf: false to turn it off, or pass an object to allow another origin.
