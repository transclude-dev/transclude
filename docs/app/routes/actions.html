<script server>
  export default async ({ action }) => ({
    notes,
    error: action?.error ?? null,
  });

  export const actions = {
    async post({ request, url }) {
      const form = await request.formData();
      const text = String(form.get('text') ?? '').trim();
      if (!text) return { error: 'a note needs some text' };

      notes.push({ id: nextId++, text });
      return Response.redirect(new URL(url), 303);
    },
  };
</script>

Keyed by method

actions is an object rather than a set of exports, because export const delete is a syntax error and an object key is not. 

export const actions = {
  async post(ctx) { … },
  async delete(ctx) { … },
  async put(ctx) { … },
};

A <form> can only send GET or POST. That is HTML, not a limit here, so a form posts an intent and a fetch caller uses the method it already has.

Answer a mutation with a redirect

Returning rendered markup from a POST leaves the browser on a POST, so every reload submits the form again. Use 303: it is the status that turns the next request into a GET.

There are two exceptions. A rejected submission changed nothing, so it comes straight back with the reason. A region request asked for markup, and a redirect is not markup. 

async post({ request, url, fragment }) {
  const result = await save(request);
  if (result.error) return result;

  // A swap has nowhere to redirect to, because the browser never left.
  if (fragment !== null) return result;

  return Response.redirect(new URL(url), 303);
}

One shape from every handler

ctx.action is typed as the union of what the handlers return. If two of them return different shapes, the loader can read neither. Return one shape from all of them.

Build them in a function, never share one. A module-level const badRequest = new Response(…) works for the first request and then answers with an empty body.

CSRF

On by default, and the only middleware the framework registers for you. It is scoped to the hole a form opens: non-GET requests carrying one of the three content types a form element can send. Set csrf: false to turn it off, or pass an object to allow another origin.
