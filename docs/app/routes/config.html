Key Default What it does
appDir 'app' Where the app lives, relative to the project root.
elementsDir 'elements' Custom elements. Relative to appDir.
cookieSecret null Signs cookies. Without one, cookies.signed throws.
csp false A Content-Security-Policy in the document, built from the hashes of what it inlines. true, or an object with directives and reportOnly.
csrf true false to turn it off, or an object passed to hono/csrf.
fragmentHeader null A request header that may name a fragment. Setting it adds that header to Vary.
fragmentParam 'fragment' The query parameter that asks for a fragment. null ships no loader on any page.
lang 'en' The lang on <html> for every page. A page or layout writing <html lang="cy"> wins over it.
metadataBase — The origin ctx.absolute() resolves against, for a canonical URL or an og:image.
outDir 'dist' Where the build writes.
feed false { hostname, title, items } mounts a feed and writes it into the build. See sitemap and feeds.
port 1960 What npm run dev and npm start both listen on. PORT in the environment wins, so a host that assigns one needs no edit.
proxy false { allow: [...] } mounts /_transclude/proxy, which fetches a document from an allowed host and answers with one fragment of it. Default deny: no key, no route. See includes.
publicDir 'public' Copied as-is to the site root. Relative to appDir, like every other directory key.
routesDir 'routes' Pages and endpoints. Relative to appDir.
sitemap false { hostname } mounts /sitemap.xml and writes it into the build. See sitemap and feeds.
strict false Full TypeScript strictness.
stylesheet — One global stylesheet, relative to the project root. null for none.
trailingSlash 'never' 'never' is strict routing and a 301. 'ignore' is the loose router.
typesFile — Where the generated declarations go.
