Call What it does
cookies.get(name) The value, or undefined.
cookies.set(name, value, options) Writes it on the response.
cookies.delete(name) Expires it.
cookies.all() Every cookie, on a null-prototype object.
cookies.signed.get(name) The value if the signature holds, else undefined.
cookies.signed.set(name, value, options) Signs and writes.

Signing

cookieSecret is what makes cookies.signed work. Without one it throws.

Use globalThis.process?.env. A runtime with no Node compatibility has no process, and a bare reference throws before anything runs.

The dev server signs with a random value for that process and prints a notice. Production does not.

A forged cookie is not a missing one

A flash message

A short-lived signed cookie, read once and then deleted, crosses a redirect exactly once.

${html(s.flash)} curl -L does not send a cookie the redirect set on the hop it follows. It arrives on the next request instead, so a flash looks broken under curl and works in practice.
