Install

npm install transclude vite typescript

Vite and TypeScript are peer dependencies. Vite builds, and TypeScript is what transclude-check runs over your templates.

Two files to start

An app is a directory with a transclude.config.js in it. That file says where everything lives, and it is the whole interface to the framework. 

// transclude.config.js
export default {
  appDir: 'app',
  routesDir: 'routes',
  partialsDir: 'partials',
  componentsDir: 'components',
  stylesheet: 'app/styles/global.css',
  publicDir: 'public',
  outDir: 'dist',
};
// vite.config.js
import { defineConfig } from 'vite';
import transclude from 'transclude';
import config from './transclude.config.js';

export default defineConfig({
  appType: 'custom',
  plugins: [transclude(config)],
});

A page

app/routes/index.html answers /. The <script server> block runs on the server and returns the data the markup reads. 

${page}

Scripts

{
  "scripts": {
    "dev": "transclude-dev",
    "build": "transclude-build",
    "start": "transclude-serve",
    "check": "transclude-check"
  }
}
Command What it does
transclude-dev Hono and Vite together, on 5173. Edits appear without a restart.
transclude-build Writes dist/. Static routes are rendered to files.
transclude-serve Serves dist/ on 3000.
transclude-check Runs tsc over every template and route.
${interpolation} is escaped. To pass markup through on purpose, wrap it in html(), which says at the call site that you meant it.
