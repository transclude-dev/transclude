HTML is the product.

A page is an .html file, the directory tree is the route table, and any fragment of a page is a URL of its own. Nothing has to run in the browser for the page to be correct.

Get started Documentation GitHub

One file is one route

The server block answers GET. Its verb exports answer everything else, so a plain form works. Mark an element fragment and it has its own URL, from the same compiled markup.

${html(s.page)}

No client runtime

A page ships JavaScript only for the elements it renders, and only when one of them has behaviour. This site ships none.

Four runtimes, one app

Node, Bun, Deno and workerd answer identically, and a test says so across ten routes.

Types without TypeScript

A misspelled field, an unknown prop and a wrong-typed one are caught from the shapes your loaders already return.

A build that is files

Prerendered, compressed once at rest, with a strong ETag per encoding. dist/static is self-contained.

Start one

A layout, two pages and a stylesheet. --template blank is less.

${html(s.start)}
