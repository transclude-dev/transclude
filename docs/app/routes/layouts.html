A layout can answer the request

A layout loader that returns a Response stops the chain, and nothing below it runs. That is what makes a login redirect a layout's job. 

export default async ({ cookies, url }) => {
  const session = await cookies.signed.get('session');
  if (!session) return Response.redirect(new URL('/login', url), 303);

  return { user: await load(session) };
};
A page behind a guard needs export const prerender = false, or the build writes a logged-out copy to a file and the guard never sees a request for it.

Sharing the response

Every loader in the chain holds the same ctx.response object, so a layout that sets a status is setting the one the server will send.
