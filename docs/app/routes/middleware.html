The order

  1. Trailing-slash redirect
  2. CSRF
  3. app/server.js
  4. Public files
  5. Routes

app/server.js runs before anything that serves bytes, so a guard covers prerendered pages and public files. Public files come before the route table, so a real file beats a [...path] catch-all.

Middleware does not run during the build. A prerendered page behind a guard is written to a file in its logged-out state.

Trailing slashes

trailingSlash sets the router mode and the redirect together.

Value Result
'never' One URL per page. /about/ redirects with a 301.
'ignore' Both URLs return 200, and neither is canonical.
