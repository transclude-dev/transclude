// app/server.js
export default (app) => {
  app.use('*', async (c, next) => {
    c.header('X-Frame-Options', 'DENY');
    await next();
  });
};

The order

Both servers build from the same function, so there is one order.

  1. Trailing-slash redirect. First, because it cleans up the URL everything after it reads.
  2. CSRF.
  3. app/server.js. Before anything that serves bytes, so a guard can cover prerendered pages and public files.
  4. Public files. Before the route table, so a real file beats a [...path] catch-all.
  5. Routes.

Every position does a job.

Middleware does not run during the build. A page behind a guard that is prerendered gets written to a file in its logged-out state, and the guard never sees a request for it.

Trailing slashes

trailingSlash sets both the router mode and the redirect, because the two exclude each other. The loose router strips the slash from the path before any middleware runs, so a redirect could never fire.

Value Result
'never' Strict routing and a 301. One URL per page.
'ignore' The loose router. Two URLs answer with 200 and neither is canonical.
