Reach for a partial first. Use a component when an element has to survive being moved around a live page.

A partial

${html(s.partial)}

Used as an element, with its props as attributes.

${html(s.use)}

The style block is hoisted into <head> once, however many times the partial appears.

Giving it behavior

A plain <script> block runs once per element. host is the element, shadow is its shadow root or null, and signal aborts when the element leaves the document.

${html(s.behavior)}

A public API

export const prototype puts members on the class. The rest of the block runs once per element.

${html(s.prototype)} host, shadow, signal and internals belong to one element. Reading one from a prototype member is a compile error.

A component

The same file shape, in components/. It gets a shadow root, a real <slot>, and it re-renders when its attributes change.

${html(s.component)}

An object or array prop is written as JSON in the attribute.

A component a form submits

export const formAssociated = true makes the browser treat the element as a field. It has to be a literal. A partial can opt in too.
