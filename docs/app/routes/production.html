A page reading ?q, a page behind a guard, and a page whose data changes are all in that group.

Caching

Build output is compressed once, and each encoding gets its own ETag.

What Cache-Control
Hashed assets public, max-age=31536000, immutable
Prerendered pages public, max-age=0, must-revalidate
The 500 page no-store, and no ETag

Public files

app/public/ is copied to dist/public and served with byte ranges, so media works.

Error pages

404.html and 500.html are prerendered and sent as bytes.

Production logs the throw and keeps it out of the body. Dev sends the stack instead.

A page ships a client entry only if something on it needs one.
