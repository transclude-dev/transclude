${html(layout)}

In routes/, .html is a page and .js is an endpoint. Elsewhere, partials/ is light DOM and components/ gets a shadow root.

A .js file in routes/ is a route. Give a helper a _ prefix to keep it out of the route table.

Names with meaning

Name Meaning
_layout.html Wraps every route in its directory and below.
[name].html One segment, in params.name.
[...path].html The rest of the path, in params.path.
404.html, 500.html Sent when a request finds nothing or fails.
_anything.js A helper, not a route.
