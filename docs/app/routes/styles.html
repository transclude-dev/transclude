What crosses a boundary

  • Custom properties inherit, so --rule on :root reaches inside a component.
  • Selectors do not. A global class lands on a page and on a partial, and stops at a component's shadow root.

So a global stylesheet can theme a component, and cannot style one.

Styles in a file

A <style> block in a page or layout is hoisted into <head>. In a partial it is scoped to that tag with :scope.

${html(s.scoped)}

Styles for swapped-in markup

A partial that arrives with a fragment brings its styles with it. They are added to <head> once, on their own. There is nothing to set up.

View transitions

Cross-document view transitions are CSS-only and opt-in. Both documents must carry the rule.

${html(s.transition)}

A name has to be unique in a document. Derive one from the data when the same element appears in a list and on a detail page.

${html(s.name)}
