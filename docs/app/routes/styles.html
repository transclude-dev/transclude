What crosses a boundary

  • Custom properties inherit, so --rule declared on :root reaches inside a component.
  • Selectors do not. A class in the global stylesheet lands on a page and on a partial, and stops at a component's shadow root.

So a global stylesheet can theme a component, and cannot style one.

Styles in a page

A <style> block in a page or layout is hoisted into <head>. In a partial it is scoped to that tag with :scope and hoisted once, however many times the partial appears. 

<style>
  :scope {
    display: block;
  }
  p {
    margin: 0;
  }
</style>

Adopted styles

<style data-transclude="tag"> in <head> records which light elements the document already has styles for. A partial swapped in from another route reads that record before adding its own, so it does not get a second copy of its rules.

View transitions

Cross-document view transitions are CSS-only and opt-in. They need full-page navigation, which is what this framework does. Both documents must carry the rule. 

@view-transition {
  navigation: auto;
}

@media (prefers-reduced-motion: reduce) {
  @view-transition {
    navigation: none;
  }
}

A name has to be unique in a document, so derive one from the data when the same element appears in a list and on a detail page. 

${transition}
