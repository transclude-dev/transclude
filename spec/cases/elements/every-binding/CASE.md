An element holding each kind of binding: text, text between static text,
attribute values, a boolean attribute, an `if` chain, an `each` with its
index, a keyed `<template each>` with an `if` in each item, a `<pre>` and a
`<textarea>`. It is here for the `bind and update` invariant, which generates
its props from the defaults. The one request shows the full render.

Source: `/docs/elements`, "A shadow element", and `design/harness-plan.md`,
"The bind/update rule, everywhere".
