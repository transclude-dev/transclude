What this site adds

${dep.name} ${dep.what}

The type is three stacks rather than three files: Neo-grotesque for the interface, Transitional for prose, Monospace Code for code. The reader's system answers with the first name it has. The page carries no @font-face and asks for no font. It reads a little differently on a Mac and on Windows. That is what a face which came with the machine looks like.

The wordmark is the exception, and it is not type. It was #transclude in IBM Plex Mono Bold. app/elements/site-mark.html draws those same letters as two outlines. That costs about 800 bytes on a compressed page, and it is one shape everywhere.

What it ships

${html(s.build)}
Pages 34 rendered to files at build time, and three that answer per request
JavaScript One inline block, 653 bytes, which applies the theme before the first paint. No runtime of ours. The explorer is the one page that ships a file, for picking a block and reading a module without leaving it
Fonts None. The wordmark is drawn, and the rest is whatever the reader already has

Shiki runs in the loader, so highlighting happens once at build time and the browser gets plain markup.

Colors and type

Contrast is measured with APCA, which reports lightness contrast as Lc. Body text clears Lc 90, everything else that is read clears Lc 75, and code tokens clear Lc 60. A test measures every pairing against the background it is used on.

The syntax themes are GitHub's high-contrast pair for the same reason: github-dark draws comments at Lc 28 on this background.
