What this site adds

${dep.name} ${dep.what}

The type uses three font stacks, not three font files. Neo-grotesque is for the interface, Transitional is for prose, and Monospace Code is for code. The reader's system uses the first font in the stack that it has. The page has no @font-face and requests no font. So the text looks a little different on a Mac and on Windows. That is normal for fonts that come with the computer.

The wordmark is the exception, and it is not text. It shows #transclude in IBM Plex Mono Bold. app/elements/site-mark.html draws those letters as two outlines. This adds about 2.3 KB to a compressed page, measured on the pages this site serves. The wordmark has the same shape everywhere.

Colors and type

This site measures contrast with APCA, which reports lightness contrast as Lc. Body text reaches at least Lc 90. All other text that people read reaches at least Lc 75. Code tokens reach at least Lc 60. A test measures every color pair against its background.

The syntax themes are GitHub's high-contrast pair for the same reason. The github-dark theme draws comments at Lc 28 on this background.
