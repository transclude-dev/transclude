Colors and type

Contrast is measured with APCA, which reports lightness contrast as Lc. Body text clears Lc 90, everything else that is read clears Lc 75, and code tokens clear Lc 60. A test measures every pairing against the background it is used on.

The syntax themes are GitHub's high-contrast pair for the same reason: github-dark draws comments at Lc 28 on this background.
