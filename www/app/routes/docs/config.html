An unknown key throws, naming it and every key there is. A misspelled key was ignored before that, which reads exactly like a key that worked.

Two spellings repeat down the table. A key that names a thing takes null for none: a stylesheet, a parser, a secret, a directory. A key that switches a feature takes true or an object that configures it, and false is off.

Paths read from two places. routesDir, elementsDir, publicDir and iconsDir sit inside appDir, because they are the app. outDir, stylesheet and typesFile are read from the project root, because a build output and a generated declarations file are not. Move appDir and the first four follow it. So does the default for typesFile, which is the one root-relative key with a directory in its default.

Key Default What it does
appDir 'app' Where the app lives, relative to the project root.
cache — Where a page held by revalidate is kept. The default is a bounded map in this process. Anything with the same get, set, delete and deleteByTag works, which is how more than one server shares one.
canonical false true writes <link rel="canonical"> on every page, naming that page's own URL. It needs metadataBase, and says so if it is missing. A page or layout writing its own replaces it.
cookieSecret null Signs cookies. Without one, cookies.signed throws. An empty string is refused at startup, because it is a secret that supplies nothing.
csp false A Content-Security-Policy in the document, built from the hashes of what it inlines. true, or an object with directives and reportOnly.
csrf true false to turn it off, or an object passed to hono/csrf.
elementsDir 'elements' Custom elements. Relative to appDir.
feed false { hostname, title, items } mounts a feed and writes it into the build. See sitemap and feeds.
fragmentHeader null A request header that may name a fragment. Setting it adds that header to Vary.
fragmentParam 'fragment' The query parameter that asks for a fragment. null turns it off, so no URL asks for one.
iconsDir 'icons' One SVG file per icon, compiled into /icons.svg as a sprite of <symbol>s. Relative to appDir. Point a <use> at one by file name: <use href="/icons.svg#check"> draws icons/check.svg.
lang 'en' The lang on <html> for every page. A page or layout writing <html lang="cy"> wins over it.
markdown null (source, file) => html. What makes a .md file under routes/ a page. It is converted before anything compiles it, so the page that comes out has a loader, elements and fragments like any other. This package ships no parser, and a .md page without this is an error naming the file. Markdown pages is the rest.
metadataBase — The origin ctx.absolute() resolves against, for a canonical URL or an og:image.
onError null (error, { request, url, method, route, phase }) for every request that fails. route names the matched route and its params, and phase says which work failed: page, fragment, action, endpoint, after or revalidate. The 500 page ships either way, and a reporter that throws is caught. Without one, the error is logged.
outDir 'dist' Where the build writes.
port 1960 What npm run dev and npm start both listen on. PORT in the environment wins, so a host that assigns one needs no edit.
precache false true writes /precache.json: every prerendered page, hashed asset and public file, with what says it changed. A hashed asset has revision: null, because its name is its version. Nothing reads it for you.
proxy false { allow: [...] } mounts /_transclude/proxy, which fetches a document from an allowed host and answers with one fragment of it. Default deny: no key, no route. See includes.
publicDir 'public' Copied as-is to the site root. Relative to appDir, like every other directory key.
routesDir 'routes' Pages and endpoints. Relative to appDir.
sitemap false { hostname } mounts /sitemap.xml and writes it into the build. See sitemap and feeds.
speculate false true writes <script type="speculationrules"> into every page. A prerendered URL may be prerendered, because no loader is left to run. A server-rendered route may only be prefetched, because its loader may read a cookie. { eagerness, exclude } for the rest.
strict false Full TypeScript strictness.
stylesheet null One global stylesheet, relative to the project root. null for none.
trailingSlash 'never' 'never' is strict routing and a 301. 'ignore' is the loose router.
typesFile 'app/transclude-env.d.ts' Where the generated declarations go, relative to the project root. The default follows appDir.
watchElements false Puts a script on every page that defines and styles an element arriving in a swap. Worth it when fragments bring in elements the page did not render.
