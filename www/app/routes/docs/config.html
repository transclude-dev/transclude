An unknown key throws an error. The error names the key and lists every valid key. A key that nothing reads looks the same as a key that worked. So it is an error, not a warning.

Two patterns repeat in the table. A key that names a thing takes null for none: a stylesheet, a parser, a secret, a directory. A key that turns on a feature takes true or an object that configures it. false turns it off.

Paths are read from two places. routesDir, elementsDir, publicDir and iconsDir are inside appDir, because they are part of the app. outDir, stylesheet and typesFile are read from the project root. A build output and a generated declarations file are not part of the app. If you move appDir, the first four move with it. The default for typesFile moves too. It is the one root-relative key with a directory in its default.

Key Default What it does
appDir 'app' Where the app lives, relative to the project root.
cache — Where the server keeps a page cached by revalidate. The default is a bounded map in this process. Any object with the same get, set, delete and deleteByTag methods works. That is how several servers share one store.
canonical false true writes <link rel="canonical"> on every page, with that page's own URL. It needs metadataBase, and says so if it is missing. If a page or layout writes its own link, that link replaces it.
cookieSecret null Signs cookies. Without it, cookies.signed throws. An empty string is refused at startup, because an empty secret protects nothing.
csp false A Content-Security-Policy in the document, built from the hashes of its inline content. true, or an object with directives and reportOnly.
csrf true false to turn it off, or an object passed to hono/csrf.
elementsDir 'elements' Custom elements. Relative to appDir. A list names several directories, read as one set. A tag in two of them is refused.
feed false { hostname, title, items } serves a feed and writes it into the build. See sitemap and feeds.
fragmentHeader null A request header that may name a fragment. Setting it adds that header to Vary.
fragmentParam 'fragment' The query parameter that asks for a fragment. null turns it off, so no URL can ask for one.
iconsDir 'icons' One SVG file per icon, compiled into /icons.svg as a sprite of <symbol>s. Relative to appDir. Point a <use> at an icon by its file name: <use href="/icons.svg#check"> draws icons/check.svg. A list names several directories, read as one set. An icon in two of them is refused.
lang 'en' The lang on <html> for every page. A page or layout that writes <html lang="cy"> overrides it.
markdown null (source, file) => html. This function turns a .md file under routes/ into a page. It converts the file before anything compiles it. So the page that comes out has a loader, elements and fragments like any other page. This package ships no parser. Without this key, a .md page is an error that names the file. Markdown pages has the details.
metadataBase — The origin that ctx.absolute() resolves against, for a canonical URL or an og:image.
onError null (error, { request, url, method, route, phase }), called for every request that fails. route names the matched route and its params. phase says which work failed: page, fragment, action, endpoint, after or revalidate. The 500 page is sent either way, and a reporter that throws is caught. Without onError, the error is logged.
outDir 'dist' Where the build writes.
permissionsPolicy false A Permissions-Policy header that lists the features this app blocks. true, or an object with features.
port 1960 The port that npm run dev and npm start both listen on. PORT in the environment overrides it, so a host that assigns a port needs no edit.
precache false true writes /precache.json. It lists every prerendered page, hashed asset and public file, with a value that shows when each one changed. A hashed asset has revision: null, because its name is its version. The framework does not read the file for you.
proxy false { allow: [...] } serves /_transclude/proxy. It fetches a document from an allowed host and answers with one fragment of it. It is off by default: with no key, there is no route. See includes.
publicDir 'public' Copied unchanged to the site root. Relative to appDir, like every other directory key.
routesDir 'routes' Pages and endpoints. Relative to appDir.
sitemap false { hostname } serves /sitemap.xml and writes it into the build. See sitemap and feeds.
speculate false true writes <script type="speculationrules"> into every page. The browser may prerender a prerendered URL, because it has no loader left to run. It may only prefetch a server-rendered route, because its loader may read a cookie. { eagerness, exclude } sets the other options.
stylesheet null One global stylesheet, relative to the project root. null for none.
trailingSlash 'never' 'never' means strict routing and a 301 redirect. 'ignore' means the loose router.
typecheck true The dev server reports type errors in the background. It never blocks a render, and it does nothing without TypeScript installed.
typecheckStrict false Full TypeScript strictness, in transclude-check, the editor and the dev server's reports.
typesFile 'app/transclude-env.d.ts' Where the generated declarations go, relative to the project root. The default follows appDir.
watchElements false Puts a script on every page. The script defines and styles an element that arrives in a swap. Use it when fragments bring in elements that the page did not render.
