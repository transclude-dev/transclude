Reporting a bug

Open an issue with the smallest page, element or config that shows the problem. Say which runtime you saw it on. A .html file that reproduces is worth more than a description of one.

Mail admin@dakroub.co instead. Say what an attacker can do and how you got there.

Running it

${html(s.setup)}

The tests need no app. npm run showcase starts the demo, which is where the browser checks live, and npm run www starts this site.

Before you send a change

CONTRIBUTING.md has the layout, the test rules and the writing style. Two things in it catch most first pull requests.

Falsify before trusting. Break the mechanism on purpose and confirm its own test fails. A test that passes both ways is not a test.

The package does not reach into the apps. examples/showcase and www depend on it by name, the way any project would. A test says so.

Code of conduct

Everyone taking part agrees to the Code of Conduct. Be kind, talk about the work rather than the person, and take new people seriously. Reports go to admin@dakroub.co and stay private.
