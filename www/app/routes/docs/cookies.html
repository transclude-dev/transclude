Call What it does
cookies.get(name) The value, or undefined.
cookies.set(name, value, options) Writes it on the response.
cookies.delete(name) Expires it.
cookies.all() Every cookie, in a null-prototype object.
cookies.signed.get(name) The value if the signature is valid, else undefined.
cookies.signed.set(name, value, options) Signs it and writes it.

The default write options are Path=/, HttpOnly, SameSite=Lax, and Secure when the request came over TLS. An option you pass replaces its default. The framework refuses sameSite: 'None' without secure: true. Every browser silently drops a cookie with that pair.

Signing

cookies.signed needs cookieSecret. Without it, cookies.signed throws.

${html(s.secret)}

Use globalThis.process?.env. A runtime without Node compatibility has no process. A bare reference to it throws before anything runs.

The dev server signs with a random value for that process, and it prints a notice. Production does not do this.

A flash message

Use a short-lived signed cookie. Read it once, and then delete it. The message then shows exactly once, after one redirect.

${html(s.flash)} curl -L does not send a cookie that a redirect set when it follows that redirect. The cookie arrives on the next request instead. So a flash looks broken in curl but works in a browser.
