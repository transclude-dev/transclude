Vite and TypeScript are optional peers, so neither arrives with the framework and both go in your own package.json. Vite builds and it serves in development; TypeScript is what npm run check drives. A built app loads neither, which is why a container that only serves one carries neither.

An app is a directory with a transclude.config.js in it. It says where everything lives.
