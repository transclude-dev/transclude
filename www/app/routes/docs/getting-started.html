Or by hand

The rest of this page shows the files that command wrote, so you can set up a project by hand.

${html(s.install)}

Vite and TypeScript are optional peer dependencies. The framework does not install them, so you add both to your own package.json. Vite builds the app and serves it in development. npm run check runs TypeScript. A built app loads neither of them. A container that only serves the app does not need them.

An app is a directory that contains a transclude.config.js file. This file tells the framework where each part of the app is.

${html(s.config)}

A project does not need a vite.config.js. The commands above make the Vite configuration for you. To add another Vite plugin, write a vite.config.js that contains only that plugin.

${html(s.vite)}

Scripts

${html(s.scripts)}
Command What it does
transclude-dev Starts the server on port 1960. Your edits appear without a restart.
transclude-build Builds the app into dist/.
transclude-serve Serves dist/ on the same port.
transclude-check Type-checks every template and route.
The server escapes every ${interpolation}. To output a value as markup, wrap it in html().
