${html(layout)}

In routes/, .html is a page and .js is an endpoint. Every file in elements/ is a custom element. It uses light DOM unless its file exports shadow.

A .js file in routes/ is a route. Start the name of a helper with _ so that it is not a route.

Special file names

Name Meaning
_layout.html Wraps every route in its directory and in the directories below it.
[name].html Matches one path segment. The value is in params.name.
[...path].html Matches the rest of the path. The value is in params.path.
404.html, 500.html Sent when no route matches a request, or when a route fails.
_anything.js A helper, not a route.
