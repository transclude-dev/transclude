Charge for an endpoint

x402 is HTTP 402 with a payload. A request with no payment gets a 402 and the terms. The client pays, and then sends the request again with a header that the server verifies. The seller gives an address to receive payment, and no private key.

@x402/hono is Hono middleware, and this server is Hono. So it needs nothing from this framework.

${html(s.x402)} ${html(s.x402Endpoint)}

gated is the part this framework adds. Middleware does not run during the build. So without gated, the build writes a paid page to a file, and anyone can get it free. An endpoint is never prerendered. So gated matters only when you charge for a page or a fragment.

x402 is for agents and API clients. A person in a browser has no wallet unless they installed one. So a paid endpoint is a better choice than a paid page.

The page

Give a fragment its own URL

With this markup, /notes?fragment=list returns only the <ul>. See fragments.

${html(s.fragment)}

Put data in the page for something else to read

A <script> with a type that the browser does not run is a data block. The compiler outputs it as written. It does not compile it as client code.

${html(s.dataBlock)}

You can still write a plain <script> or one with type="module". The compiler still compiles and bundles those. The type decides which happens.

The contents are raw text, so a ${'$'}{…} could close the element or the statement around it. So the compiler refuses it. Pass the whole block through html(), or put the value in an attribute and read it from there.

Show the same content twice

The server resolves an include, so no JavaScript ships. See includes.

${html(s.include)}

A reusable element

It uses light DOM. So page CSS reaches it, and the server sends no JavaScript. See elements.

${html(s.element)}

Open a dialog with no JavaScript

command and commandfor are built into the platform. A button names its target and the action to take. You write no listener and no script. The button still works as a button for a keyboard and a screen reader.

${html(s.popover)}

To animate a dialog, you need two things. @starting-style sets the style that the open state starts from. allow-discrete lets display and the top layer animate in the transition, instead of changing at once.

${html(s.popoverCss)}

An accordion with one section open at a time

Give a group of <details> the same name. Then only one can be open, the same as radio buttons. Opening one closes the others, and no script runs.

${html(s.accordion)}

Hidden content that page search can still find

hidden="until-found" hides content, but find in page can still find it. Ctrl+F shows the content and scrolls to it. It also fires beforematch, so a <details> around it can open itself.

${html(s.untilFound)}

Plain hidden removes the text from the page completely. A reader searches for a word they know is there, and the browser finds nothing.
