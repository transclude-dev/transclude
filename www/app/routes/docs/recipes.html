Charge for an endpoint

x402 is HTTP 402 with a payload. A request with no payment gets a 402 and the terms. The client pays, and the retry carries a header the server verifies. The seller supplies a receiving address and no private key.

@x402/hono is Hono middleware, and the server here is Hono, so it needs nothing from this framework.

${html(s.x402)} ${html(s.x402Endpoint)}

gated is the half that is ours. Middleware does not run during the build, so without it a paid page is written to a file and given away. An endpoint is never prerendered. This matters the moment you charge for a page or a fragment.

x402 is aimed at agents and API clients. A person in a browser has no wallet unless they installed one. So a paid page is a worse trade today than a paid endpoint.

Put data in the page for something else to read

A <script> with a type the browser does not execute is a data block. It is emitted as written, rather than compiled as client code.

${html(s.dataBlock)}

A plain <script> and one with type="module" are still yours to write, and are still compiled and bundled. The type is what decides.

The contents are raw text, so a ${'$'}{…} could close the element or the statement around it. The compiler refuses it. Pass the whole block through html(), or put the value in an attribute and read it from there.

Open a dialog with no JavaScript

command and commandfor are the platform's own invoker: a button names what it acts on and what to do. No listener, no script, and the button stays a button for a keyboard and a screen reader.

${html(s.popover)}

Animating it needs two things a dialog makes awkward. @starting-style gives the open state somewhere to come from. allow-discrete lets display and the top layer take part in the transition instead of snapping.

${html(s.popoverCss)}

An accordion where one is open at a time

A shared name makes a group of <details> exclusive, the way radio buttons are. Opening one closes the rest, and nothing runs.

${html(s.accordion)}

Collapsed content that a page search can still find

hidden="until-found" hides content but leaves it findable. Ctrl+F reveals it, scrolls to it, and fires beforematch so a <details> around it can open itself.

${html(s.untilFound)}

Plain hidden takes the text out of the page entirely. A reader searching for a word they know is there is told it is not.
