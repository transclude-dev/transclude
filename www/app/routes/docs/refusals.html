The compiler refuses ${count} kinds of mistake. This page reads the list from the compiler itself. So it shows what your version does, not what somebody remembered.

A refusal rejects only code that already did not do what it seemed to do. So the list can grow in a minor version, and a longer list breaks nothing that worked. See decisions and limits for what a version number means here.

A … marks a gap that the message fills in: a tag name, an export or a file. This page shows the fixed part of each message. The full message from the compiler also names the item, and it usually tells you what to change.
