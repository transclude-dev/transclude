The compiler refuses ${count} kinds of mistake. This page is read out of the compiler itself. So it says what the version you have does, rather than what somebody remembered.

A refusal rejects code that was already not doing what it looked like it did. That is why the list can grow in a minor version, and why growing it is not the same as breaking something. See decisions and limits for what a version number means here.

A … is a hole the message fills in: a tag name, an export, a file. What is printed here is the fixed part, which is the sentence. What the compiler prints you also names the thing and, usually, the change to make.
