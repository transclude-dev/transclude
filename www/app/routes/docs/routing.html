The loader

A <script server> block runs on the server. Its default export takes the request context and returns the data the markup reads.

${html(s.loader)} The loader and the markup that reads it change together, so they are one file to open and one file to review. The block is compiled into the route and never reaches the browser. Why transclude makes the longer case.

The context

Field What it is
absolute absolute('/og.png') against metadataBase.
action What this page's action returned, if one ran.
cookies Read and write, signed or plain.
fragment The fragment asked for, or null.
params The path segments this route captured.
request The Request. null while prerendering, which is the only time there is none.
response The status and headers for the response.
route The matched route, including its path.
url The full URL, as a string. new URL(url) for its parts.

Interpolation

\${…} reads what the loader returned and is always escaped, so a value carrying <script> arrives as text. html() is the one way out, and it is in scope in every file with nothing to import.

${html(s.interpolation)} It marks a value as markup you vouch for. It sanitizes nothing, so html() around anything a visitor typed is how a page runs somebody else's script. Security has the rest.

In an attribute

An attribute value takes ${empty} too, whole or in part, as many times as you like.

${html(s.attributes)}

The value is escaped by attribute rules, which are not the text rules. What a value is decides what the attribute becomes.

The value The attribute
false, null, undefined dropped, rather than written as a string
true the name on its own, as disabled
an object or an array JSON, which is how an element reads it back
anything else the string, escaped
Only a value is read. An interpolation in the attribute name is a compile error, because emitting it would put ${empty} into the page as those characters. To pick between two spellings, put the condition in the value.

Directives

A directive's value reads as an expression, not as a string. There is no ${empty} inside one, and no quotes around a name.

${html(s.directives)}

key tells the browser which item is which, so input values and focus survive a reorder.
