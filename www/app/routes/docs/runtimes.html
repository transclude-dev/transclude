Cloudflare Workers is named because it is where most people meet it. What is actually targeted is workerd, the runtime underneath, so anywhere that runs it runs this.

Workers refuses to compile WebAssembly at runtime, and a loader that reaches something built on it fails there and nowhere else. This site hit exactly that: its syntax highlighter compiles Wasm, so every prerendered page was fine and the one URL that renders live returned 500. A prerendered page never runs its loader in production, which is what hides this until something asks for a fragment.

The Node, Bun and Deno adapters come from the package and only listen. worker.js belongs to the app.

What differs

Each difference from Node is one argument to createApp.

Node Cloudflare
Bytes The filesystem dist/server/assets.js
Hashing node:crypto WebCrypto, so hash is awaited
Compression node:zlib null. The edge does it.
Range requests 206 200
There is no process.env on Workers, so the app is built when the first request comes in and takes its config from env. Reading a secret at import time gives undefined.
