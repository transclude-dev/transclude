#transclude
An HTML-first server-side web framework.

Every icon system on the web is built on a feature nobody calls by its name. You write a shape once, give it an id, and point at it from anywhere.

Three elements, one definition. Change the path and all three change. Nothing runs to make that happen. That is transclusion, and the browser has shipped a working version since 2011.

It works for shapes. That is the whole of it. There is no HTML equivalent, and the piece I wrote this week is about the gap where one should be.

SVG already does transclusion

What shipped

0.9.0, and the part of it worth having is export const draft = true. The dev server serves a draft so you can read it at its real URL on a real phone. The build leaves it out, and says which pages it skipped rather than letting you find out from the live site.

Nine examples are running rather than waiting in a repository. TodoMVC is seven actions through one POST handler and zero bytes of JavaScript, which is easier to believe with the page open.

Four more posts are written and sitting as drafts, which is what the draft export was for. They arrive over the next few weeks rather than all at once.

What I got wrong

The form you used to subscribe wrote to nothing for a while, and told you it had worked.

On Cloudflare a worker is handed its database connection in an object that only exists once a request arrives. The code that needs it runs elsewhere, so I kept that object in a module variable. Set on the way in, read on the way out.

Two bundlers touch that file, and each inlined its own copy. The value went into one copy and was read from the other, which was still empty. So the form answered, the page said to check your inbox, and the row went to a fallback meant for running locally.

Nothing logged anything. I found it by looking at the table. A module you import twice can be two modules. Keeping the value on globalThis fixed it: one slot per isolate, however many copies exist.
